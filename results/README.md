# Предварительные результаты

CSV восстановлены из выводов терминала, полученных на MacBook Air M4. Исходные CSV с компьютера здесь отсутствуют. Сохранена показанная точность: миллисекунды и три знака ГиБ. Это не новые запуски и не сгенерированные измерения.

runs_from_terminal.csv содержит прогрев и пять измеряемых повторов для каждой серии. summary.csv содержит медианы измеряемых повторов. Вопрос и лимит одинаковы, ответ — laptop.

Серии:

- 4bit_512_initial: первый benchmark.
- 4bit_1024: увеличенный вход.
- 4bit_1536_initial: нестабильная серия; причина не установлена.
- 4bit_1536_repeat: стабильный повтор.
- 4bit_512_after_load: малый вход после повторной серии 1536.
- 4bit_512_offline: основной ориентир 4 бит.
- 8bit_512_offline: сравнение 8 бит.

Загрузка около 62 секунд в двух сериях совпала с переключением VPN и не считается показателем локального чтения весов. Она не входит во время запроса.

Первый CLI-запуск через /usr/bin/time -l дал 4,10 с на весь процесс, maximum RSS 6 137 643 008 байт и peak memory footprint 6 859 085 152 байта. Эти показатели не смешиваются со временем запросов и пиком MLX.

Личные исходные фотографии и снимки Activity Monitor не публикуются. Для точного воспроизведения исторических результатов нужны исходные изображения, ревизии checkpoint и полный lock-файл окружения. Пока выводы ограничены пилотными измерениями.
